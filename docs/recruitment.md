# Who joins the Mouri, by episode

The full player guide, with the exact triggers from the event scripts and all craftsmen, is `docs/recruit_guide.html`. This file is the first profile-based list.

Taken from the officer profiles (PROFILE.E3, `work/source/text/ui_units.json`). Each profile has one version per story outcome; a "not joined" version marks an optional recruit. The profiles say who joins and in which episode, not the exact trigger (adjacent, attack, survive...). That needs the battle/event scripts. Craftsmen have no profiles and are not listed.

Episode numbers are the "(Ep. N)" tags in the profile text; where there is no tag, "by Ep. N" is the first episode the joined version shows.
